# 스크린샷 흐름 인덱스

## 사용자 흐름

| 흐름 | 화면 진행 순서 | 캡처 위치 |
| --- | --- | --- |
| 일기 작성 | 작성 화면 진입 → 사진 추가 → 내용 입력 → 공개 범위 설정 → 등록 → 캘린더와 일기 상세 확인 | [모바일](diary-create-flow/mobile/) · [데스크톱](diary-create-flow/desktop/) |
| 일기 수정 | 일기 상세 → 일기 메뉴 → 수정 화면 → 내용 변경 → 수정된 일기 상세 확인 | [모바일](diary-edit-flow/mobile/) · [데스크톱](diary-edit-flow/desktop/) |
| 일기 삭제 | 일기 상세 → 삭제 메뉴 → 삭제 후 화면 이동 → 삭제된 일기에 접근할 수 없는지 확인 | [모바일](diary-delete-flow/mobile/) · [데스크톱](diary-delete-flow/desktop/) |
| 상세 화면에서 댓글 작성 | 일기 상세 → 댓글 영역 → 댓글 입력 → 등록 → 작성된 댓글과 더보기 메뉴 확인 | [모바일](comment-detail-flow/mobile/) · [데스크톱](comment-detail-flow/desktop/) |
| 피드에서 댓글 작성 | 피드 → 댓글 입력 → 등록 → 댓글 모달에서 작성한 댓글 확인 | [모바일](comment-feed-flow/mobile/) · [데스크톱](comment-feed-flow/desktop/) |
| 댓글 수정 | 기존 댓글 → 더보기 메뉴 → 수정 선택 → 내용 변경 → 수정된 댓글 확인 | [모바일](comment-edit-flow/mobile/) · [데스크톱](comment-edit-flow/desktop/) |
| 댓글 삭제 | 기존 댓글 → 더보기 메뉴 → 삭제 선택 → 댓글 삭제 결과 확인 | [모바일](comment-delete-flow/mobile/) · [데스크톱](comment-delete-flow/desktop/) |
| 피드 좋아요 | 좋아요 선택 전 피드 → 좋아요 선택 → 새로고침 후 좋아요 유지 확인 | [모바일](feed-like-flow/mobile/) · [데스크톱](feed-like-flow/desktop/) |
| 친구 요청과 취소 | 피드·프로필·작성자 정보에서 친구 추가 → 요청 상태 확인 → 취소 확인 → 취소 결과 확인, 피드 작성자 선택 → 프로필 이동 | [모바일](friend-request-elements-flow/mobile/) · [데스크톱](friend-request-elements-flow/desktop/) |
| 좋아요 알림 확인 | 알림 목록 → 좋아요 알림 선택 → 연결된 일기 상세 → 읽음 처리된 알림 목록 확인 | [모바일](notification-click-flow/mobile/) · [데스크톱](notification-click-flow/desktop/) |
| 댓글 알림 확인 | 알림 목록 → 댓글 알림 선택 → 연결된 일기 상세 → 댓글 확인 → 읽음 처리된 알림 목록 확인 | [모바일](notification-click-flow/mobile/) · [데스크톱](notification-click-flow/desktop/) |
